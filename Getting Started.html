Your local workspace for maps, operating economics and explainable location comparisons.

1. Open your workspace

  1. Extract the complete downloaded ZIP into a folder.
  2. Double-click SitePilot.exe. Keep the dist and runtime folders beside it.
  3. Your default browser opens automatically. No terminal commands or Node installation are required.

Success: you see the Home screen with an interactive open map and a SitePilot icon in the Windows notification area.

To reopen the app, double-click SitePilot.exe again. To quit, right-click its notification-area icon and choose Quit SitePilot.

2. Start with the open map

  1. The Home screen immediately shows OpenStreetMap. No API key is needed.
  2. Search an address including its city, click the map, or enter independently collected latitude, longitude.
  3. Choose your business type and reporting currency, then Create project.
  4. Add 3–5 locations in Map Explorer. Drag pins to adjust them; independent coordinates save automatically.

Success: candidates reappear with their pins when you reload or import a project backup.

3. Add evidence when you need it

  1. Open Settings → Connections → Open data.
  2. Enable manual neighborhood searches, choose a community service and Test connection. Apply settings.
  3. Select a candidate in Map Explorer and choose Retrieve nearby data.
  4. Review mapped matches and coverage warnings. In Location Analysis, add your own business-specific demand observations and premises checks, with a date and method.

Success: source labels distinguish mapped observations, user observations, estimates and calculated scenarios.

Public services can time out or be incomplete. Zero API matches do not prove no businesses exist. Missing data remains unknown; use independent field evidence when a service is unavailable.

4. Understand the economics

  1. Enter rent, other fixed operating costs, contribution margin, average transaction value and trading days.
  2. Enter assumed daily transactions only if you have a scenario to test. Blank means unknown.
  3. Add setup investment, cash reserves and a preferred rent budget if useful.
  4. Compare Locations shows common criterion scores, break-even sales, conditional profit, sensitivity charts and risks. Open calculation details for each result.
  5. Decision Report downloads an HTML briefing or CSV. Print / Save PDF opens your browser print dialog.

Success: you can explain each candidate's score, break-even requirement, assumptions and downside scenario.

5. Optional Google Maps and Amap

Open Settings → Connections for provider-specific instructions and an explicit connection test. Google needs a restricted browser key with Maps JavaScript API, Places API (New) and billing enabled. Amap needs a Web JS key and matching security code. Keys stay in memory; re-enter them after reload.

Provider requests may incur charges. Google / Amap discovery content stays on the provider's own map and does not feed portable derived scores. Save independent open-map pins for permanent locations. See README for coordinate expiry and usage restrictions.

6. Keep your work

Projects save in this browser profile. Save project downloads a JSON backup; Open project restores it. Independent coordinates and licensed open-data observations persist. Restricted provider caches and credentials are excluded from backups. Use the same browser and local origin when upgrading.

Try a worked example to explore comparisons without entering data. Every example input is explicitly synthetic.

Read the result carefully

API search results are samples, not a full business census or a footfall estimate. Location weights are editable preferences. Access is a geographic proxy, not a verified walking route or step-free access assessment. Financial outputs are conditional on your sales assumptions. Verify demand, access, permits and lease terms in person.

Need help? Read README.md for troubleshooting and provider setup, and docs/methodology.md for the formulas.
